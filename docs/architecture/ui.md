# UI direction

## From `AGENTS.md`

**UI direction accepted, design deferred (August 3, 2026):** The current setup screen is provisional. Do not spend Phase 0 polishing isolated screens into a final visual system. As workflows accumulate, Meridian should become an interactive application shell with persistent navigation and clear access to accounts, transactions, spending, investments, strategies, and later systems. Implement new UI so it can move into that shell; do not treat the current page composition as the long-term dashboard design.

## From `PLAN.md` §9

**UI direction accepted; intentional design deferred.** The current manual setup page is functional scaffolding, not the target dashboard design. Once enough workflows exist to design navigation from real use, Meridian should adopt a persistent application shell/menu that makes accounts, transactions, spending, investments, strategies, and later systems easy to move between. Until then, new presentation work should remain coherent and responsive without prematurely polishing a final visual language.
